# Понятное обращение · VDA.VC

Переносимый модуль правила 1.0.1: пять вариантов → только нужное уточнение → два вопроса → редактируемый черновик. Можно сразу написать своими словами. Никакой автоматической оценки людей или обязательной оплаты за просьбу о помощи.

## Запуск

Из каталога модуля: `python3 -m http.server 8096 --bind 127.0.0.1`.
Открыть `http://127.0.0.1:8096/`.
Тесты: `node --test flow.test.mjs`.

## Три поверхности, одна логика

- Сайт/мобильный браузер: `index.html` и `app.mjs`; оформление использует текущие публичные токены VDA.VC. Доставка пока ручная: копирование или сохранение текста.
- Telegram Mini App: тот же адрес с `?surface=telegram` подключает официальный SDK, вызывает `ready`/`expand`. Запуск внутри Telegram, регистрация URL и реальная доставка не проверены. Наличие manifest не означает готовое нативное iOS/Android-приложение или проверенную установку.
- Telegram-бот: `bot-adapter.mjs` возвращает следующий вопрос и не более пяти вариантов. Это чистый адаптер; он не вызывает Telegram API. Подключение делает владелец существующего бота через его backend; сохранять и дедуплицировать состояние в существующем контуре, не создавать вторую CRM.

## Внедрение

`flow.mjs` владеет названиями маршрутов и переходами. Смена маршрута сбрасывает зависимые ответы. Максимальное пожелание необязательно и не переносится в принятое обязательство. Конфигурацию владельца можно задать до `app.mjs`: `window.InteractionIntakeConfig={owner:'Ваше имя'}`. Замените название, ссылки, иконку и manifest для своего проекта.

Серверное получение, доставка, принятие работы и выполнение результата должны иметь отдельные статусы. Подключать сохранение и передачу к существующему VDAI OS после согласования схемы. Не доверять `initDataUnsafe`; при будущей серверной Telegram-интеграции валидировать initData и его срок на сервере. Секреты, токены, переписки и внутренние проверки границ в модуль не входят.

По умолчанию нет фоновых POST, аналитики, localStorage и записи ответов. При закрытии страницы черновик теряется — сохраните текст вручную. Автоматической расшифровки голосовых пока нет: готовый текст голосового можно вставить в вопросы. Контакт пользователя не спрашивается, пока не подключён реальный канал отправки.
